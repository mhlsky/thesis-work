## 描述

该数据集包含**125 组时长 1 小时**的船舶运动仿真数据，仿真涵盖多种海况，船舶在**纵荡 - 横荡 - 艏摇 - 横摇**四自由度下做随机机动运动。基准船型为佩雷斯等人 [1] 提出的巡逻船模型，本研究在其基础上增设**一对对称布置的全回转舵桨**。

同时，本文依据**伊舍伍德风场模型**[2] 模拟风载荷；采用**JONSWAP 海浪谱**[3] 生成风生海浪，并通过**波浪力响应幅值算子（RAO）** 计算对应的波浪作用力。

船舶模型、伊舍伍德风模型、波浪力响应幅值算子以及 JONSWAP 海浪谱的实现代码，均可在**福森与佩雷斯**开发的海洋系统仿真工具箱中获取 [4]。

数据集划分为**常规工况集（96 小时）** 与**分布外测试集（OOD，29 小时）**。其中常规工况集按 **60% 训练集 - 10% 验证集 - 30% 测试集** 比例划分，分布外数据集仅用作测试评估。

本数据集用于**多步预测场景下非线性系统辨识方法**的性能评估。系统辨识的输入变量为：双螺旋桨轴转速、舵桨方位角及风速；观测状态（输出变量）包括：纵荡速度、横荡速度、横摇角速度、艏摇角速度、横摇角以及风攻角。

关于数据集文件结构与`.tab`文件各变量说明，详见`README.txt`文档。

本研究由**德国科学基金会（DFG）** 在德国卓越战略项目（EXC 2075 – 项目编号 390740016）资助完成，并得到斯图加特仿真科学中心（SimTech）的支持。

## 字段说明

在 **train（训练集）、validation（验证集）、test（测试集）** 每个目录下，均为**逗号分隔表格文件**，包含以下字段：

| 字段    | 单位      | 中文释义                                                     |
| :------ | :-------- | :----------------------------------------------------------- |
| time    | 秒        | 时间戳，采样频率 1 赫兹                                      |
| n       | 1 / 秒    | 螺旋桨轴转速；左右舵桨转速同步，恒为正值                     |
| deltal  | 弧度      | 左舵桨方位角                                                 |
| deltar  | 弧度      | 右舵桨方位角                                                 |
| Vw      | 米 / 秒   | 惯性坐标系下风速                                             |
| alpha_x | 无量纲    | 风攻角余弦值 \(\cos(\alpha)\)，该角度已基于船体相对坐标系归一化 |
| alpha_y | 无量纲    | 风攻角正弦值 \(\sin(\alpha)\)，释义同上                      |
| u       | 米 / 秒   | 船体坐标系纵向（进退）速度                                   |
| v       | 米 / 秒   | 船体坐标系横向（横荡）速度                                   |
| p       | 弧度 / 秒 | 船体坐标系横摇角速度                                         |
| r       | 弧度 / 秒 | 船体坐标系艏摇角速度                                         |
| phi     | 弧度      | 相对惯性坐标系的船体横摇角                                   |
