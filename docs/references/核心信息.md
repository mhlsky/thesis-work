一、课题定位
研究方向：船舶 / 海洋平台海事仿真场景下的运动姿态时序预测
核心模型：以 xLSTM 为基础模型进行自定义改进
落地定位：不做真实船舶硬件部署，全程面向海事仿真平台、海洋平台仿真系统对接，用于仿真验证、算法对照、姿态时序预测建模
二、数据集完整信息
数据时长：125 小时
采样频率：1Hz，每秒 1 个采样点
总样本量：450000 条时序样本点，近 45 万级、数十万级时序数据规模
特征维度及字段：
time：时间戳
n：螺旋桨轴转速
deltal、deltar：左右舵桨方位角
Vw：风速
alpha_x、alpha_y：风攻角余弦、正弦分量
u、v：船体坐标系纵荡、横荡速度
p：横摇角速度
r：艏摇角速度
phi：横摇角度
任务类型：多变量长时序回归预测，预测船舶 / 平台姿态时序
三、基础模型相关知识
1. LSTM 固有缺陷
   单一记忆单元，长时序信息易衰减、易遗忘
   线性门控机制，深层网络易梯度消失，无法搭建深层大模型
   状态更新离散跳变，物理适配性差，难贴合船舶连续惯性运动
   纯数据驱动，难以融入海洋运动物理约束
2. Transformer 固有缺陷
   自注意力复杂度 O(L²)，计算量大、推理慢
   不适合长时序、实时仿真低延迟场景
   参数量大、冗余度高，不适配仿真平台轻量化推理
3. xLSTM 原生结构与优势
   两大核心结构：
   双记忆结构：线性记忆捕捉短期海浪 / 姿态扰动；指数记忆捕捉船舶长周期运动规律
   指数门控：替代 LSTM 线性门控，梯度传播稳定，深层不消失，可构建深层模型
   核心优点：
   计算复杂度 O (L) 线性复杂度，轻量化、推理快
   内部状态连续平滑更新，贴合船舶 / 海洋平台惯性、阻尼物理运动
   天然适配融入动力学物理约束，预测不出现角度跳变、超限等反物理结果
   长时序依赖建模能力远超传统 LSTM
   四、本人三大改进点（原理 + 作用）
1. VMD 变分模态分解
   原理：将原始姿态时序自适应拆分为趋势项 + 周期项 + 随机噪声项
   作用：去噪解耦，分离海浪扰动与固有运动周期，降低噪声干扰，提升模型对有效运动特征的学习能力
2. 引入线性注意力
   原理：把标准注意力 O (L²) 降为线性复杂度 O (L)
   作用：保留关键时序特征捕捉能力，同时压缩计算量、加快推理，适配仿真平台实时性要求
3. 融入船舶 / 海洋平台动力学约束
   三类约束：
   边界约束：姿态角、角速度限定物理合理范围，不超限
   平滑性约束：姿态变化连续不突变，符合刚体运动惯性
   动力学耦合约束：六自由度运动之间耦合关联建模
   作用：预测结果符合海洋工程物理机理，极端海况仿真下鲁棒性更强，无跳变、发散现象
   五、仿真系统业务逻辑
   预测输出用途：对接海事仿真平台 / 海洋平台仿真系统
   预测后流向：作为仿真系统前馈输入，用于运动响应仿真、控制算法验证、作业场景仿真评估
   实时性要求：仿真闭环运行需要低延迟、毫秒级推理，必须兼顾精度与推理效率
   无实船硬件部署，全部研究价值聚焦仿真验证、模型对比、时序算法研究
   六、论文考核关键问答要点（可用于写作 + 答辩）
   改进点：VMD 时序分解 + 线性注意力嵌入 + 船舶动力学多约束融入 xLSTM
   性能提升：预测误差降低、强海况鲁棒性提升、推理速度更快、输出符合物理规律
   数据来源：125h、1Hz 实测 / 仿真时序数据，共 45 万时序样本点，足够支撑模型训练验证
   系统输入：船舶航行参数、环境风场参数、六自由度姿态与角速度多源时序特征
   研究定位：不落地实船，服务海事仿真、海洋平台仿真领域
