# 项目整体说明
## 1. 项目背景与任务
本项目基于船舶四自由度运动时序数据集，开展船舶姿态多步预测研究，建模纵荡u、横荡v、横摇p、艏摇r、横摇角phi时序变化规律。

## 2. 数据集结构
- 数据采样频率：1 Hz
- 总时长：125小时仿真数据
- 划分：routine常规工况96h，OOD域外工况29h
- routine 按 60/10/30 分为 train / validation / test
- OOD 仅用作测试集

## 3. 输入输出变量
输入：双桨转速n、左/右舵桨方位角deltal/deltar、风速Vw、风攻角
输出：u, v, p, r, phi 船舶运动状态量

## 4. 模型与任务类型
- 任务：时序多步预测、非线性系统辨识
- 模型：LSTM / xLSTM / PatchTST 等时序模型
- 评估指标：MAE、RMSE、R²

## 5. 代码结构规范
- 数据处理：data/ 目录
- 模型定义：model/ 目录
- 训练逻辑：train/ 目录
- 工具函数：utils/ 目录
